# V3 quality review

V3 uses a folded, two-piece M in a warm copper and violet palette. The route crossing both pieces connects the mark to the engineering narrative. The visual hierarchy starts with identity, specialization, work navigation and honors, then moves through capabilities, three work studies in a single composition, and a chronological journey.

## Refinements implemented

- **Composition and legibility.** Replaced B’s isometric module header with a personal signature, richer relief and a separate mobile composition. Moved honors into the opening, shortened the anchors, and pulled the compact capability map nearer to the first mobile screen.
- **Evidence and editorial structure.** Replaced the repeated case bands with a shared gallery and three distinct domain studies. Numoo shows a Flask handoff to a team model, NCM layers conceptual host metrics and logs, and the portfolio pairs English and Arabic layouts. The native table connects tools to work, and work entries retain actual roles and independent links.
- **Browser and motion review.** Corrected stretched gallery lettering, adjusted the mobile mark-to-caption spacing, darkened relief in dark mode, and added underlines to links discovered by the dark-mode axe check. Motion stages separate the pieces, seat them, draw a route, and resolve it in a single traversal. The still counterpart contains no animation markup.
