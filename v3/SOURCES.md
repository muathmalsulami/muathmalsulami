# Vector sources

The signature, engineering diagrams, project studies and timeline are original vectors in generate.cjs. The work studies illustrate an interface-to-model handoff, training metrics and logs, and mirrored language layouts. The plotted lines are conceptual.

The technology glyphs are vendored from [the pinned Simple Icons source](https://github.com/simple-icons/simple-icons/tree/801eaab5b70f4933137069397ebbd2ce5f9ad56e/icons). Simple Icons provides normalized monochrome versions of the brand shapes. Their [repository license](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md) covers the icon distribution. Brand marks retain their owners’ trademark terms. The JavaScript mark is community-authored.

| Mark | Source referenced by the icon maintainer |
| --- | --- |
| HTML5 | [W3C](https://www.w3.org/html/logo/) |
| CSS | [CSS-Next](https://github.com/CSS-Next/logo.css) |
| JavaScript | [Community JavaScript logo](https://github.com/voodootikigod/logo.js) |
| Python | [Python Software Foundation](https://www.python.org/community/logos/) |
| Flask | [Pallets](https://github.com/pallets/flask/tree/main/docs/_static) |
| Docker | [Docker media resources](https://www.docker.com/company/newsroom/media-resources/) |
| Prometheus | [Prometheus project](https://prometheus.io/) |
| Grafana | [Grafana](https://grafana.com/) |
| Git | [Git logo source and terms](https://git-scm.com/community/logos) |
| GitHub | [GitHub logos](https://github.com/logos) |

Run node v3/generate.cjs and node v3/verify.cjs from the repository root. Generation is deterministic and requires no external requests. The GitHub workflow runs the original profile and prototype validators as well as V3 checks.
