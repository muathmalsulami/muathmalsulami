## Generate and verify

From this directory, run `node generate.cjs` and `node readmes.cjs`, then `node verify.cjs`. The shared generators preserve palette, project facts and validation while allowing each README and hero to take a different form. All logo and icon geometry is authored in the generator. Project strips are conceptual artwork. Essential content is native Markdown or GitHub-supported HTML.

Screenshots were captured from the separate GitHub-rendered READMEs in Edge. Motion previews are silent sampled GIFs of the actual GitHub hero, with a resting frame at the end. The GIFs are review evidence and do not load in the prototype READMEs.
